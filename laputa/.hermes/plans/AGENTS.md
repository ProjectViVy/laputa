## Naming Convention

```

```

Example: `2026-06-30_010300-laputa-eino-rhythm-autodream.md`

- **Date:** generated date (UTC)
- **Time:** timestamp (HHMMSS)
- **Module:** `laputa`, `mentle`, or `garden`
- **Feature:** brief feature name
- **Suffix:** always `-autodream.md`

## Execution Workflow

1. **Generate:** Hermes creates plan file in this directory
2. **Review:** Engineer reviews goal, architecture, and tasks
3. **Execute:** Subagent runs tasks sequentially, committing after each phase
4. **Verify:** Engineer runs final validation and accepts/rejects
5. **Archive:** Completed plan moves to `docs/archive/` with commit hash reference

---

## Archive Policy

Plans are archived when:

- Plan is superseded by newer version
- Feature is cancelled

Archived plans remain in version control as audit trail.
