## Purpose

Planning documents outline proposed features, trade-offs, and implementation considerations before detailed specification.

---

## Structure

Each planning document should include:

1. **Title** — short superpower name
2. **Problem statement** — what pain point does this solve?
3. **Proposed approach** — how would it work?
4. **Trade-offs** — what's the cost?
5. **Alternatives** — what else was considered?
6. **Success criteria** — how do we measure success?
7. **Related work** — references to existing implementations

---
