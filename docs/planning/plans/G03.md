## 文件与顺序（开工后）

拟新增 `garden_hermes/{proposal,review}.py`、`tests/test_proposals.py`、`tests/test_review_policy.py`。无 writer/队列引用。

- [ ] 空/重复证据直接 no_change；仅当前受准投影，必要人格片段可外发，整篇私有 SOUL/HOST/reasoning/工具原文禁止自动外发。
- [ ] 至多一次 ctx.llm 逻辑人格归纳，任务内候选；无工具循环/自动修复重试/长期素材库，记录真实 usage。
- [ ] 严校来源、段别、输出预算、未知字段/无 jsonschema；反例允许修订/否定，不强制漂移。
- [ ] 自动允许段与保护段独立判断；改变使命/删除使命/新建使命或绕权限边界必须拒绝或 needs_user_authorization，不能接受模型自填 grant。
- [ ] 用户明确使命变更授权绑定 persona/当前版本/具体变更；普通人格阶段不自动执行使命变更。源使命不匹配获准 pin 时不能继续自动组装。
- [ ] 用户事实/记忆/技能只分流，原生机制继续负责；模型前后和交付 apply 前检查取消/卸载/绑定仍有效。
