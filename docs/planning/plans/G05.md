## 顺序

- [ ] 固定实际运行/源码/解释器版本，capability结果区分supported/unsupported/unverified，不凭官网能力宣称本地可用。
- [ ] 在隔离合成home准备可辨识的SOUL fixture，用真实Hermes新session构建/请求路径核验实际身份块；不得只调用一个文件读取函数或听模型自述就通过。
- [ ] 测试探针固定使用当前已有 `pre_api_request` 的 `system_prompt` 字段（`agent/turn_api_request.py:43-88`），仅在获准的隔离/真实验收会话临时注册read-only回调；在进程内比较预期原生渲染身份块与实际请求，回调只产出bool/安全版本摘要，立即卸载，不保存或输出完整payload，不采reasoning。先fake provider验证，再单独授权真实调用。这是验收探针，不是产品默认Observer采集功能。若固定版本缺字段或请求链不经过该hook，返回unverified，停止而不偷偷patch core。
- [ ] 缓存旧session恢复、真正新session、正常/seeded压缩、人格overlay、扫描/截断、profile路由分别验证。
- [ ] 激活证明只留私有session/期望版本/观察摘要；不公开完整system prompt。
- [ ] 长会话刷新不支持就返回unsupported；不调用repair/reset/强制compress当前QQ会话来制造成功。
