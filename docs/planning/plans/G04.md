## 授权后的顺序

- [ ] 根据冻结 writer 合同先做隔离故障/竞写测试；锁范围与可约束写者集合写清。
- [ ] 在 control 提交锁内核验 home、generation、同意/策略、decision、候选精确基线、有效渲染预算；before==after 直接 no_change。
- [ ] 若 D01 选片段自动写，严格证明片段外字节不变；片段标记初始化/改变需要独立批准，不在 apply 中暗中补建。
- [ ] 持久不可变 before/after 与 intent 并 fsync；任一步失败不动目标。
- [ ] 按 writer 合同提交原生目标，独立重新打开回读，成功后持久 receipt；目标与 receipt 不是跨文件 ACID。
- [ ] 目标可能已变但结果失败则 outcome_unknown；只比较 current/before/after，不自动重写，不推断写者归因。
- [ ] 同 operation 仅查询，同 ID 不同 payload 冲突；observed_before 不自行获得重试许可。
- [ ] 回滚必须新许可/intent，current 精确等于旧 after 且仍有写入条件；有后续编辑即拒绝，回滚后仍待激活验证。
