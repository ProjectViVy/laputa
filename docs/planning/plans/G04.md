## 关卡通过后的顺序

- [ ] 从可信绑定解析唯一目标；校验许可、候选出处、精确baseline与有效预算。
- [ ] 依据已批准并发合同获取写权限；不假称锁能约束外部编辑器。
- [ ] 私有持久化包含精确before/after的intent；失败则绝不写目标。
- [ ] 原生写入→独立回读→结果持久化；目标和回执不是多文件ACID。
- [ ] 相同operation查询既有状态；同ID不同内容冲突。写后异常为unknown，不自动重试。
- [ ] reconcile只比较current与before/after；两者都不同就unknown_conflict，不能推断来源或覆盖新内容。
- [ ] rollback作为新操作，要求current仍精确等于本操作after且满足同一写合同；否则拒绝，再进行新的激活验证。
