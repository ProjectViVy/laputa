- [ ] 先写 fire-site、早退、取消与前台有界测试；投影只当前 user/final assistant 可见字段，先有 local consent，模型/正文不能给身份。

- [ ] 明确拆开 fork client 清理和整任务结束：provider 阶段退出只移除/释放原生 fork 引用；父 run token、cancel flag/完成管理保留到 persona provider-capable 阶段退出。拟加安全 detach fork 步骤，不能去中断已释放 fork 来假装取消辅助请求。
- [ ] 取消前置检查与短提交准入有明确先后：取消先到无提交；提交已经开始只报告其真实结果，不倒称已撤销。前台仍保持原生有界等待。

- [ ] 不加数据库、任务扫描、持久重排、outbox 或独立 persona worker。
