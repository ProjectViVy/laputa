- [ ] 先冻结 D03 的源码副本、最小变更面与测试入口，写 full-terminal 合同测试；不只往 VALID_HOOKS 加字符串。

- [ ] 实际 admission 后 started；线程启动失败、早退、provider 不支持、取消、异常和正常完成均由统一外层结算，终态只发一次。

- [ ] 消费回调仅验证/短持久化/唤醒；惰性工作器串行处理 ready，默认无周期轮询。无 end、错绑定、错 schema 拒绝自动分析。
- [ ] pause/unload/revoke 增 generation；模拟迟到回调/LLM 无提交资格，且不强抢仍被活线程占用的 work.lock。
- [ ] 测试 fail-open、上下文传播、restart 恢复边界；事件落盘前骤死不许宣称重放/不丢。

关键顺序：`freeze_projection -> native_enqueue -> admit_attempt -> started -> capture_actual_result -> cleanup -> finished_once -> persisted_ready -> lazy_worker`。
