## 验收层次

1. 纯函数/合成 Markdown/fake completion：解析、使命、组装、版本和故障注入。
2. 固定隔离 Hermes 树/合成共享根与 home/fake provider：真实 stage/取消/队列/加载路径，不接生产数据。
3. 单独批准目录/初始使命 pin/迁移接管、模型预算/启用/写入/新 session 后的真实松柏闭环。

分别报告，前两层不替代第三层。任意外部写者 CAS、跨文件 ACID、跨重启任务必达和控制台不是本期验收承诺。见 [status](status.json) 与 [Story](plans/index.md)。
