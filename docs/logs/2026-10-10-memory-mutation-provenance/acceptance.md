# Acceptance

An ordinary memory effect retains its actual originating references in canonical authority; current content and supplied new provenance change together under CAS. Stale updates cannot alter content/source metadata. Foreign source scopes are denied, while admitted personal-to-workspace citations remain allowed.

This validates mapping and bound read-union checks. It does not prove existence/authenticity of arbitrary caller-authored record IDs or complete hostile-memory authorization, profile isolation, lifecycle and S11 acceptance. Actual App positive references are generated from the real ingestion window. Those remaining cases stay in the local queue.
