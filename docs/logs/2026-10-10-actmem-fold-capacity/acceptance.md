# Acceptance

A captured pair can be folded and each resulting capsule read through the native public reader; recovery returns the original IDs and complete sources. A source with unrepresentable metadata refuses folding while retaining its head entry and writing no invalid capsule. Existing archive-first recovery and stale-fold boundaries remain covered.

Formal App/session-delete acceptance is not implied by these kernel tests. S05 remains open until the complete same-candidate proof passes.
