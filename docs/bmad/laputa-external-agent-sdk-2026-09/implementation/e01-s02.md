## Delivered behavior

- Adds `POST /v2/agent/bind`.
- Requires an authenticated `PrincipalAgent` bearer token; no token is unauthorized and a non-Agent principal cannot bind.
- Strict JSON requires `profile_id`, `agent_id`, `platform`, and `session_id`; unknown fields are rejected.
- Uses server canonical profile ID: `Server.AgentProfileID`, then `GARDEN_AGENT_PROFILE_ID`, then `default`.
- Rejects profile mismatch with `403 profile_forbidden`; client body/header cannot select another authority profile.
- Returns only validated binding metadata, Agent principal and request ID. It creates no Garden Session, Run, Journal, database row or second authority.
- Manifest now advertises only verified live `agent.bind`, with principal requirement `agent`.
