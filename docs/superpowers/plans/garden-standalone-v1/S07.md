# S07: Selected facts and standalone autonomy removal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task in the assigned development session. Steps use checkbox (`- [ ]`) syntax for tracking. Preserve the selected GPT-6.1-SOL HIGH executor; do not dispatch a new implementer per task.

**Goal:** Save reviewed selected experience as a provenance-linked fact and remove standalone self-evolution without breaking live DIVA effects/recovery.

**Architecture:** Use existing authorized mutations/receipts for fact save, plus narrow operation-scoped source validation for cross-scope human-selected facts. Remove standalone provider/mailbox routes and assembly at replacement; preserve exactly the shared Domain/Mission contracts still used by DIVA.

**Tech Stack:** Existing Go 1.26.4 modules, SQLite via modernc, Laputa Markdown authorities, and React/TypeScript console where needed. Host language exceptions are stated in their owning tasks; no new service.

**Spec:** [Standalone Garden v1](../../specs/2026-10-12-garden-standalone-v1-design.md), source/design revision `3f14f8f4135790591e746d78058314ca9a46551b`; accepted ADR-0012/0014/0016/0018 remain binding as scoped there.

## Global Constraints

- Reuse existing `ProfileID` as the stable subject. Membership access is `read` or `read_write`, per spec §4.1.
- "All subjects in an installation share one selected backend database; bound adapters are views, not separate stores."
- "Persona and Recap remain subject-private, outside shared spaces."
- "WORLD is tool-only; ACTMEM is never Frozen Core."
- "No automatic BML→Mentle conversion." "No background data conversion at boot."
- No general IAM/per-record ACL, token delegation, taint framework or optional subsystem rewrite, per spec §§1.3/4/9.
- "Discovery is read-only; installation places inert adapter files only. Bindings start disabled."
- Q2 release timing and Q3 restricted-session Recap remain undecided. No runtime implementation before plan review; no production migration, PR, merge, deployment, credentials or user-host configuration is authorized by this planning delivery.

4. Removing an autonomy package must not remove live DIVA Apply/Lookup/Mission guards — Task 2 shared-contract test.
5. A disabled legacy toggle/provider still present in standalone is incomplete removal — Task 2 runtime/import audit.
