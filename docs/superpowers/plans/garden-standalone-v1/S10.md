## Scope, files and contracts

Supersedes the baseline PreviewCLI/file-region prescription. Native Persona hooks are now required; automatic memory lifecycle remains excluded. Do not create hosts.PreviewCLI or a generic config writer. Historical plan remains in git.

Consumes S15 NativePromptRequest/PromptProjection and S03 bound MCP operations. Targets: Codex rust-v0.162.1 / 092d3acd6bec3e3a14bdc7e7a2810ab628ab759d; Claude Code v2.1.296 / public release SHA 2301018b1f61073c501a8e7a4813ef48c239163b, closed-binary qualification pending.

**Proposed files:** `garden/cmd/garden-host-context/main.go`, `main_test.go`; `garden/adapters/codex-cli/.codex-plugin/plugin.json`, `hooks/hooks.json`, `README.md`; equivalent `garden/adapters/claude-code/.claude-plugin/plugin.json`, `hooks/hooks.json`, `README.md`.
**Existing:** `garden/cmd/garden-mcp/main.go`, `main_test.go` (necessary explicit-tool fixes only).

**Bridge interface:** `run(ctx context.Context, in io.Reader, out, diagnostics io.Writer, cfg Config, client *http.Client) error`. Config fields Endpoint, BindingID, CredentialFile, HostKind, HostVersion, HostInstance, ScopeFingerprint, CWD are strings. Command accepts `--config <Garden-owned private JSON path>`; config references credential file, never embeds token. Hook templates resolve owner-provided config, not a discovered user home.
Read at most 64 KiB stdin; accept UserPromptSubmit/SessionStart only; require session_id/cwd, skip agent_id/subagent unless separately bound/qualified. Ignore prompt/transcript. Canonical cwd must match approved scope. Send S15 request with bearer/X-Garden-Session. Success stdout is exactly `{"hookSpecificOutput":{"hookEventName":"<input event>","additionalContext":"<markdown>"}}`. Expected invalid/unavailable/locked/revoked input returns no contribution, bounded stderr diagnostic and successful exit, preserving unrelated host work. No partial JSON or content/secrets in logs.
