**Architecture:** Reuse S02 host bindings and S03 memory operations; add one small internal hosts package for managed blocks, backups and status. Host-specific adapters follow S09/S10, so this common core does not need guessed host API versions or automatic lifecycle behavior.

**Tech Stack:** Existing Go 1.26.4 modules, SQLite via modernc, Laputa Markdown authorities, and React/TypeScript console where needed. Host language exceptions are stated in their owning tasks; no new service.

**Spec:** [Standalone Garden v1](../../specs/2026-10-12-garden-standalone-v1-design.md), source/design revision `3f14f8f4135790591e746d78058314ca9a46551b`; accepted ADR-0012/0014/0016/0018 remain binding as scoped there.

**Files:**
- Create (proposed): `garden/internal/hosts/projection.go`, `garden/internal/hosts/files.go`, `garden/internal/hosts/status.go`, `garden/internal/hosts/service.go`, `garden/internal/hosts/projection_test.go`, `garden/internal/hosts/files_test.go`, `garden/internal/hosts/status_test.go`, `garden/agentapi/hosts.go`, `garden/internal/server/host_handlers.go`.
- Modify: `garden/internal/registry/bindings.go`, `garden/agentapi/access.go`, `garden/internal/server/server.go`; metadata in existing garden.db, no new queue/service dependency.

**Interfaces:**
- Consumes S02 HostBinding/HostControls/SetHostControls/RevokeHostBinding and S03 authorized memory/capture. Host adapters use fixed bound credentials/session; no profile choice in adapter model input.
- Produces `hosts.FilePlan{BindingID, Path, OriginalHash, ManagedHash, ProposedContent, AdapterVersion string; SourceRevisions map[string]uint64}`; `ProjectionRequest{BindingID string; Kinds []persona.Kind; Path string}`. `(*hosts.Service).Preview(ctx,ProjectionRequest)(FilePlan,error)`, `Apply(ctx,FilePlan)(HostStatus,error)`, `Revoke(ctx,bindingID string)(HostStatus,error)`. Owner-selected absolute target paths, never values from models.
- `HostStatus{ManualAction,ManualPath string; BindingID string; SavedRevisions,WrittenRevisions map[string]uint64; WrittenHash,LoadedHash,SessionID,AdapterVersion,State string}`; State exactly `inactive|pending_reload|unknown|conflict|revoked|loaded`. LoadedRevisions are included only with exact acknowledged projection. Additive ManualAction is empty, `apply_projection` or `remove_projection`; ManualPath identifies the owner-selected file requiring action. A 409 includes this status in `details.host_status`. `AcknowledgeLoaded(ctx,bindingID,sessionID,hash string) (HostStatus,error)` accepts authenticated host/session evidence; no generic hook-success acknowledgement.
- Marker grammar in files.go: `<!-- Garden BEGIN binding=<opaque-id> -->` / `<!-- Garden END binding=<opaque-id> -->`, exactly one pair; reject duplicates/malformed/nested blocks. Empty/unmanaged file initial full-file hash is preview precondition; preserve all bytes outside region. No credential/source secrets in projection.
- Default preview selects Identity/Relationship/Redline/User; Dream/Dark require owner explicit selection, Mission separately explicit; WORLD/ACTMEM forbidden static projection. Source revisions are read from Persona authority; frozen sessions not overwritten. Persist original private backup path/hash, last whole-file/region hash, adapter version, target revisions in Garden binding metadata.
- Proposed owner `/v2/host-bindings/{id}/projection` preview/apply/status/revoke routes; JSON maps to above types. Status is authoritative server state; loaded may remain unknown forever for hosts lacking evidence. Common core automatically creates only an absent target with atomic no-clobber linking; existing files require manual application of the reviewed managed region while preserving current user text. Successful manual application is observed against persisted exact intent, never assumed loaded. Revocation invalidates authorization and preserves the host file, returning conflict/manual cleanup while managed markers remain; a retry after owner removal acknowledges without writing. Native automatic Persona delivery now uses S15/S16/S17/S10 prompt hooks. Do not route native config activation through FilePlan or revive shared-file replacement. Discovery/install remains inert.
